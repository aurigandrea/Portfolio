# Portfolio Website

Personal portfolio website for Dr Andrea Kocsis - Web Developer specializing in academic and research projects.

#If you want to fork it

## Features

- Responsive design for all devices
- Interactive project gallery with video previews
- Contact form with EmailJS integration
- Animated gradient hero section
- Project modals with detailed information

## Technologies

- HTML5
- CSS3 (with animations and gradients)
- JavaScript (ES6+)
- EmailJS for contact form
- Google Fonts (Poppins)

## Setup

 For contact form functionality, update EmailJS credentials in `script.js`:
   - `EMAILJS_PUBLIC_KEY`
   - `EMAILJS_SERVICE_ID`
   - `EMAILJS_TEMPLATE_ID`

## Structure

- `index.html` - Main HTML structure
- `styles.css` - All styling and animations
- `script.js` - Interactive functionality
- `img/` - Project images and videos
